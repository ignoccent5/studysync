# StudySync — Tech Meets Campus Life (Dev 2.0)

A real-time, crowd-sourced campus hub that shows live study-spot capacity, noise vibes, outlet availability, and drop-in peer study sessions at a glance.

## Features
- **Live Study-Spot Pulse:** Color-coded `Quiet`, `Moderate`, and `Packed` status cards.
- **1-Tap Crowd Check-In:** Zero-friction status updates with exponential time-decay confidence weighting.
- **Smart Spot Ranking:** Automatically sorts campus spaces based on your study vibe and outlet preferences.
- **Drop-In Study Sessions:** Host or join active course study blocks right where you are.
